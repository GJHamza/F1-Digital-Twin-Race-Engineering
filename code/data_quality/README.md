# F1 Digital Twin — Data Quality & Statistical Audit Suite

This directory contains the audit framework for evaluating synthetic telemetry datasets generated by the F1 Digital Twin platform.

---

## 📁 Package Layout

```
code/data_quality/
├── __init__.py           # Package init
├── quality_audit.py      # Schema, completeness, uniqueness, bounds & monotonicity audits
├── statistical_audit.py  # Summary statistics, Pearson correlations & scenario differentiation
└── README.md             # Technical documentation
```

---

## 📊 Modules & Capabilities

### 1. `quality_audit.py`
- **Schema Compliance**: Evaluates events against `code/schema/schema_v1.json` via `validate_telemetry()`.
- **Completeness Audit**: Measures missing/null rates for 23 key telemetry attributes.
- **Uniqueness Audit**: Detects duplicate `event_id` and duplicate timestamps within session.
- **Boundary Validation**: Checks numerical bounds for speed, RPM, gear, throttle, brake, fuel, and tire variables.
- **Monotonicity Check**: Verifies chronological timestamps, decreasing fuel level, increasing fuel used, and non-decreasing tire wear.
- **Anomaly Audit**: Reports anomaly event count, rate, and breakdown by anomaly type (`TIRE_OVERHEAT`, `ENGINE_OVERHEAT`, etc.).

### 2. `statistical_audit.py`
- **Summary Statistics**: Computes `count`, `min`, `max`, `mean`, `median`, `std`, `p5`, `p25`, `p75`, `p95` for 15 numerical telemetry fields.
- **Pearson Correlation Audit**: Evaluates physical relationship coefficients ($r$) such as throttle $\leftrightarrow$ engine load, speed $\leftrightarrow$ downforce, fuel level $\leftrightarrow$ tire wear.
- **Scenario Differentiation**: Compares mean telemetry profiles across scenarios.
- **Offline Plot Generator**: Generates visual audit charts saved under `reports/g2_3/`.

## 💡 Usage Example

```python
from data_generator.generator_v2 import SyntheticGeneratorV2
from data_quality.quality_audit import run_full_quality_audit
from data_quality.statistical_audit import (
    extract_numeric_dataframe,
    calculate_statistical_summary,
    calculate_pearson_correlations
)

gen = SyntheticGeneratorV2(seed=42)
events = gen.generate_dataset("RACE_DRY", sessions_count=1, laps_per_session=5)

# Quality audit
quality_report = run_full_quality_audit(events)
print("Schema Compliance:", quality_report["schema_compliance_pct"], "%")

# Statistical audit
df = extract_numeric_dataframe(events)
stats = calculate_statistical_summary(df)
correlations = calculate_pearson_correlations(df)
```

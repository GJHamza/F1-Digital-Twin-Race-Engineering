ABOUT THE PROJECT

What is F1 Digital Twin?

This project is a complete Formula 1 simulation ecosystem that replicates the real-world workflow of a race engineering team. From vehicle selection to wind tunnel testing, every piece of telemetry is captured, streamed via Apache Kafka, stored in MongoDB Atlas, and analyzed through an engineering dashboard.

FEATURES

Three Pillars of the Ecosystem

01

3D Test Bench

Select a vehicle and run it on a rolling road dyno. Activate the wind tunnel, emergency brakes, or tire stress tests — all in real-time 3D with Three.js.

02

Kafka Telemetry Pipeline

Every data point flows through Apache Kafka in real-time. Speed, G-force, tire temperature, drag coefficients — all streamed to MongoDB Atlas instantly.

03

Engineering Dashboard

A Streamlit-powered analytics interface for race engineers. Analyze historical runs, compare setups, and optimize car performance with data-driven insights.
